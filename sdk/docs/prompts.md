# 可直接使用的需求示例

以下句子帮助你描述目标。具体 AI 操作流程由仓库独立 Skill `datapanel-workflows` 提供。

## 发现数据

> 使用 `$datapanel-workflows`，查找当前可用的 BTC 盘口数据，告诉我时间范围、字段与缺口。只查询，不提交计算。

## 冻结输入与报价

> 为我选定的数据区间建立平台内快照，并准备一个 60 秒、最多 1 积分的 CPU 特征计算报价。先不要启动训练，也不要导出原始行情。

## 自定义特征训练

> 用我提供的特征文件跑一次 CPU 模型示例，预算最多 1 积分，时限 120 秒。完成后取回 JSON 模型，比较样本外误差与零预测基线。

## 固定 GPU 模板报价

> 检查我的 input.json，使用固定 GPU 模板入口上传并报价，预算最多 1 积分。仅报价，不提交训练。说明它是否支持我的网络结构和设备数量。

## 增量研究计划

> 根据已经完成研究处理的分区 ID，规划下一批平台内输入，列出缺口和未处理分区。只做计划。

## 取回自己的结果

> 下载我指定的私有结果资产，核验大小和 SHA256，告诉我本地保存位置。不要运行下载的源码。

## 恢复已有任务

> 继续原来的训练目录，查询已保存任务的状态。不要因为查询超时就创建另一个任务。

## 取消指定任务

> 取消我提供 ID 的任务，并告诉我它目前的实际状态。取消请求被接收不等于资源已释放或账单已结算。
